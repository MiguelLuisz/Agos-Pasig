# Agos Pasig

A student-led educational website on water pollution in the Pasig River, made for GE - A2101 at Mapúa Malayan Digital College.

**Live site:** https://miguelluisz.github.io/Agos-Pasig/

## Files

- `index.html`: page content (Home and The River)
- `assets/css/styles.css`: all styles
- `assets/js/main.js`: page switching, phone menu, chapter bar, sources list
- `assets/images/`: photos (WebP, 640px and 1280px versions) and logo
